0. Notation and conventions

We work with BFD even moments. The moment vector the flow models is

x=(Mf,  Mr,  M1,  M2)∈R4,x = (M_f,\; M_r,\; M_1,\; M_2) \in \mathbb{R}^4,

flux monopole MfM_f, a size/second-radial moment MrM_r, and the two spin-2 quadrupoles M1,M2M_1, M_2. Only MfM_f (dimension 0) enters the selection, so the identities of the other three never matter below — but it is worth keeping in mind that MfM_f is spin-0 while shear g=(g1,g2)g=(g_1,g_2) is spin-2. That single fact drives the whole qualitative structure of the result.

Two "spaces" for the PQR arrays:

  • Probability space: P,  Q=∇gP,  R=∇g2PP,\;Q=\nabla_g P,\;R=\nabla_g^2 P — plain derivatives of a probability PP. This is what selection_pqr returns, in flow column order [P, Q1, Q2, R11, R22, R12][P,\,Q_1,\,Q_2,\,R_{11},\,R_{22},\,R_{12}].
  • Log space (the accumulation quantities the estimator actually sums):
Qtot≡∇glog⁡P=QP,Rtot≡−∇g2log⁡P=Q⊗QP2−RP.Q_{\mathrm{tot}} \equiv \nabla_g \log P = \frac{Q}{P}, \qquad R_{\mathrm{tot}} \equiv -\nabla_g^2 \log P = \frac{Q\otimes Q}{P^2} - \frac{R}{P}.

qr_log_totals performs exactly this map (statistics.py:63, via bfd.logPqr).

The BFD maximum-likelihood shear from a catalogue is

  g^=(∑iRtot,i)−1(∑iQtot,i)  (0.1)\boxed{\;\hat g = \Big(\textstyle\sum_i R_{\mathrm{tot},i}\Big)^{-1}\Big(\textstyle\sum_i Q_{\mathrm{tot},i}\Big)\;} \tag{0.1}

with equal target weight. A key invariance: any per-object constant prefactor on [P,Q,R][P,Q,R] cancels in Qtot,RtotQ_{\mathrm{tot}}, R_{\mathrm{tot}}, so normalization of the flow prior is irrelevant to g^\hat g. (This is why we can be cavalier about overall constants throughout.)

Throughout, Φ\Phi is the standard normal CDF and φ=Φ′\varphi=\Phi' its pdf; recall φ′(u)=−u φ(u)\varphi'(u) = -u\,\varphi(u).

1. Why there is a correction at all

1.1 Selection multiplies each likelihood by a truncation factor

Suppose we only keep objects whose measured flux moment falls in a band [fmin⁡,fmax⁡][f_{\min}, f_{\max}]. For a single object with data MiM_i, the likelihood of the data given that it was selected is the truncated, renormalized density

p(Mi∣g, selected)=p(Mi∣g)Psel,i(g),p(M_i \mid g,\ \text{selected}) = \frac{p(M_i \mid g)}{P_{\mathrm{sel},i}(g)},

where Psel,i(g)P_{\mathrm{sel},i}(g) is the probability that an object drawn from the sheared population passes the cut, evaluated with object ii's own noise level. The denominator is exactly the normalization of the truncated distribution: it is gg-dependent because shear reshapes the population and hence changes the fraction that survives the cut.

Sum the log-likelihood over the selected sample:

log⁡L(g)=∑i[log⁡p(Mi∣g)  −  log⁡Psel,i(g)].(1.1)\log \mathcal{L}(g) = \sum_i \Big[\log p(M_i\mid g) \;-\; \log P_{\mathrm{sel},i}(g)\Big]. \tag{1.1}

1.2 The correction is the selection's own PQR, subtracted per object

Everything downstream follows from differentiating (1.1). Each object contributes its measured log-derivatives minus the log-derivatives of its selection probability:

∇glog⁡L=∑i[ Qtot,i−Qtot,isel ],−∇g2log⁡L=∑i[ Rtot,i−Rtot,isel ],\nabla_g \log\mathcal{L} = \sum_i \Big[\,Q_{\mathrm{tot},i} - Q^{\mathrm{sel}}_{\mathrm{tot},i}\,\Big], \qquad -\nabla_g^2 \log\mathcal{L} = \sum_i \Big[\,R_{\mathrm{tot},i} - R^{\mathrm{sel}}_{\mathrm{tot},i}\,\Big],

where Qtotsel=Qsel/PselQ^{\mathrm{sel}}_{\mathrm{tot}} = Q^{\mathrm{sel}}/P_{\mathrm{sel}} and Rtotsel=Qsel ⁣⊗Qsel/Psel2−Rsel/PselR^{\mathrm{sel}}_{\mathrm{tot}} = Q^{\mathrm{sel}}\!\otimes Q^{\mathrm{sel}}/P_{\mathrm{sel}}^2 - R^{\mathrm{sel}}/P_{\mathrm{sel}} are the log-totals of the selection probability, computed with the identical P,Q,R ⁣→ ⁣Qtot,RtotP,Q,R\!\to\!Q_{\mathrm{tot}},R_{\mathrm{tot}} recipe. Setting the gradient to zero and linearizing gives the corrected estimator

  g^sel=(∑iRtot,i−∑iRtot,isel)−1(∑iQtot,i−∑iQtot,isel).  (1.2)\boxed{\; \hat g_{\mathrm{sel}} = \Big(\textstyle\sum_i R_{\mathrm{tot},i} - \sum_i R^{\mathrm{sel}}_{\mathrm{tot},i}\Big)^{-1} \Big(\textstyle\sum_i Q_{\mathrm{tot},i} - \sum_i Q^{\mathrm{sel}}_{\mathrm{tot},i}\Big). \;} \tag{1.2}

This is precisely apply_selection (statistics.py:128): compute the arm's log-totals, subtract the per-object selection log-totals, then do the usual linear solve. With no selection terms it collapses to (0.1) / pqr2g.

Read (1.2) carefully — three structural consequences you will see mirrored in code:

  1. There is one selection term per selected object, not one global term. The log⁡Psel,i\log P_{\mathrm{sel},i} in (1.1) depends on object ii's noise σf,i\sigma_{f,i}, so the subtraction is per object and carries that object's noise.
  2. The correction enters through the same log-space machinery as the measurement, so it is literally another PQR passed through qr_log_totals.
  3. Because it is attached per object, a bootstrap resample moves the measured and selection sums together, preserving their correlation (§5.3).

Everything else in this note is about computing one ingredient: the selection probability Psel(g)P_{\mathrm{sel}}(g) and its two gg-derivatives.

2. The selection probability Psel(g)P_{\mathrm{sel}}(g)

2.1 Passing probability at fixed true moments

The cut acts on the measured flux, which is the true flux moment Mf(x)M_f(x) plus Gaussian measurement noise of standard deviation σf\sigma_f (the square root of the [0,0][0,0] entry of the moment covariance, σf,i=Σi[0,0]\sigma_{f,i}=\sqrt{\Sigma_i[0,0]}). Conditional on the true moment vector xx, the probability of landing in the band is a difference of Gaussian CDFs — the hard band, smeared by noise into a smooth "box":

s(x)  =  Pr⁡ ⁣(fmin⁡≤Mf(x)+ε≤fmax⁡),ε∼N(0,σf2)s(x) \;=\; \Pr\!\big(f_{\min} \le M_f(x)+\varepsilon \le f_{\max}\big),\quad \varepsilon\sim\mathcal N(0,\sigma_f^2)
  =  Φ ⁣(fmax⁡−Mf(x)σf)−Φ ⁣(fmin⁡−Mf(x)σf)  ∈[0,1].(2.1)\;=\; \Phi\!\Big(\frac{f_{\max}-M_f(x)}{\sigma_f}\Big) - \Phi\!\Big(\frac{f_{\min}-M_f(x)}{\sigma_f}\Big) \;\in [0,1]. \tag{2.1}

This is the s at inference.py:177. Note ss is bounded and infinitely smooth in MfM_f — remember this; it is why §6 can use plain Monte Carlo.

2.2 Marginalize over the sheared prior

PselP_{\mathrm{sel}} is the population-average passing probability under the flow prior conditioned on shear gg:

Psel(g)  =  ∫pθ(x∣g) s(x) dx  =  Ex∼pθ(⋅∣g)[ s(x) ].(2.2)P_{\mathrm{sel}}(g) \;=\; \int p_\theta(x\mid g)\, s(x)\, dx \;=\; \mathbb{E}_{x\sim p_\theta(\cdot\mid g)}\big[\,s(x)\,\big]. \tag{2.2}

pθ(⋅∣g)p_\theta(\cdot\mid g) is the trained conditional normalizing-flow prior. The subtlety that makes this tractable is how we take the expectation, which is the whole content of the next section.

3. Reparameterized (pathwise) Monte Carlo

3.1 Push the gg-dependence into the integrand

The flow is a bijection x=T(z;g,sx)x = T(z; g, s_x) with base variable z∼N(0,I4)z\sim\mathcal N(0, I_4), and by construction the pushforward of the base normal is pθ(⋅∣g)p_\theta(\cdot\mid g). Change variables x→zx\to z in (2.2):

Psel(g)=∫N(z;0,I) s(T(z;g,sx)) dz=Ez∼N(0,I)[ s(T(z;g)) ].(3.1)P_{\mathrm{sel}}(g) = \int \mathcal N(z;0,I)\, s\big(T(z;g,s_x)\big)\, dz = \mathbb{E}_{z\sim\mathcal N(0,I)}\Big[\, s\big(T(z;g)\big)\,\Big]. \tag{3.1}

The integrating measure no longer depends on gg. All shear dependence now lives inside the integrand, through the map TT. This is the reparameterization (a.k.a. pathwise-gradient) trick, and it is what lets us freeze the randomness.

3.2 Freeze zz, then differentiate the estimator directly

Draw a single fixed batch z1,…,zN∼N(0,I)z_1,\dots,z_N \sim \mathcal N(0,I) (inference.py:171) and form

P^sel(g)=1N∑i=1Ns(T(zi;g)),zi frozen.(3.2)\widehat P_{\mathrm{sel}}(g) = \frac1N \sum_{i=1}^{N} s\big(T(z_i; g)\big), \qquad z_i \text{ frozen.} \tag{3.2}

Because the sample points do not move with gg, we may differentiate under the sum:

∇gP^sel(g)=1N∑i∇g s(T(zi;g)),∇g2P^sel(g)=1N∑i∇g2 s(T(zi;g)).(3.3)\nabla_g \widehat P_{\mathrm{sel}}(g) = \frac1N\sum_i \nabla_g\, s\big(T(z_i;g)\big), \qquad \nabla_g^2 \widehat P_{\mathrm{sel}}(g) = \frac1N\sum_i \nabla_g^2\, s\big(T(z_i;g)\big). \tag{3.3}

These are what jax.grad(P_sel) and jax.hessian(P_sel) compute at inference.py:182-183.

3.3 Why not sample x∼pθ(⋅∣g)x\sim p_\theta(\cdot\mid g) directly?

If you sampled in data space, gg would sit in the density, and the gradient would be the score-function (REINFORCE) estimator

∇gPsel=Ex∼pθ(⋅∣g)[ s(x) ∇glog⁡pθ(x∣g) ],\nabla_g P_{\mathrm{sel}} = \mathbb{E}_{x\sim p_\theta(\cdot\mid g)}\big[\, s(x)\,\nabla_g \log p_\theta(x\mid g)\,\big],

whose variance is typically orders of magnitude larger, and which does not share random numbers across nearby gg. The pathwise estimator (3.3) reuses the same ziz_i for every gg (common random numbers), so the finite-sample Psel(g)P_{\mathrm{sel}}(g) is a smooth surface in gg and its curvature is not swamped by MC noise. This is the technical reason the correction can be estimated to the precision that a second-derivative (RR) requires.

4. The chain rule, by hand

jax does this automatically, but for an advanced reader the closed form is the point: it shows which flow derivative carries the signal and why the first-order term is essentially zero.

4.1 The three composed maps

For a single frozen draw ziz_i, shear enters ss through a chain of three maps:

g  →  T    x0=[T(zi;g)]0  →destandardize  Mf=10 std0 x0+mean0  →(2.1)  s.(4.1)g \;\xrightarrow{\;T\;}\; x_0 = \big[T(z_i;g)\big]_0 \;\xrightarrow{\text{destandardize}}\; M_f = 10^{\,\mathrm{std}_0\, x_0 + \mathrm{mean}_0} \;\xrightarrow{(2.1)}\; s. \tag{4.1}

Only dimension 0 (flux) is involved. The middle step inverts the flow's dimension-0 standardizer, which stored log⁡10Mf\log_{10} M_f; hence Mf=10std0x0+mean0M_f = 10^{\mathrm{std}_0 x_0 + \mathrm{mean}_0} at inference.py:176. Write λ≡ln⁡10\lambda \equiv \ln 10 for brevity.

Define the two standardized band edges ue=(fe−Mf)/σfu_e = (f_e - M_f)/\sigma_f for e∈{min⁡,max⁡}e\in\{\min,\max\}, and note that both edges depend on gg only through MfM_f, so

∂ue∂ga=−1σf∂Mf∂ga(same for both edges).(4.2)\frac{\partial u_e}{\partial g_a} = -\frac1{\sigma_f}\frac{\partial M_f}{\partial g_a} \quad\text{(same for both edges).} \tag{4.2}

The flux derivatives, from Mf=eλ(std0x0+mean0)M_f = e^{\lambda(\mathrm{std}_0 x_0 + \mathrm{mean}_0)}:

∂Mf∂ga=Mf λ std0 ∂x0∂ga,(4.3)\frac{\partial M_f}{\partial g_a} = M_f\,\lambda\,\mathrm{std}_0\,\frac{\partial x_0}{\partial g_a}, \tag{4.3}
∂2Mf∂ga∂gb=Mf λ std0[ λ std0 ∂x0∂ga∂x0∂gb+∂2x0∂ga∂gb ].(4.4)\frac{\partial^2 M_f}{\partial g_a \partial g_b} = M_f\,\lambda\,\mathrm{std}_0\Big[\,\lambda\,\mathrm{std}_0\,\frac{\partial x_0}{\partial g_a}\frac{\partial x_0}{\partial g_b} + \frac{\partial^2 x_0}{\partial g_a\partial g_b}\,\Big]. \tag{4.4}

Here ∂x0/∂g\partial x_0/\partial g is the flow's Jacobian of the flux output w.r.t. the shear condition, and ∂2x0/∂g2\partial^2 x_0/\partial g^2 its Hessian — these are the only places the trained network enters.

4.2 First derivative QselQ^{\mathrm{sel}}

Differentiate (2.1) and use (4.2). With the "edge weight" D≡φ(umax⁡)−φ(umin⁡)D \equiv \varphi(u_{\max}) - \varphi(u_{\min}):

∂s∂ga=φ(umax⁡)∂umax⁡∂ga−φ(umin⁡)∂umin⁡∂ga=−Dσf ∂Mf∂ga=−λ std0σf Mf D ∂x0∂ga.(4.5)\frac{\partial s}{\partial g_a} = \varphi(u_{\max})\frac{\partial u_{\max}}{\partial g_a} - \varphi(u_{\min})\frac{\partial u_{\min}}{\partial g_a} = -\frac{D}{\sigma_f}\,\frac{\partial M_f}{\partial g_a} = -\frac{\lambda\,\mathrm{std}_0}{\sigma_f}\, M_f\, D\, \frac{\partial x_0}{\partial g_a}. \tag{4.5}

Then Qasel=1N∑i∂si/∂gaQ^{\mathrm{sel}}_a = \frac1N\sum_i \partial s_i/\partial g_a.

4.3 Why Qsel≈0Q^{\mathrm{sel}}\approx 0: a spin selection rule

Everything in (4.5) is generic except ∂x0/∂ga\partial x_0/\partial g_a — the linear response of the flux monopole to shear. Flux is spin-0; shear is spin-2. To first order a shear reshapes the profile against the fixed isotropic weight, and the spin-2 perturbation integrates to zero against a spin-0 moment by angular orthogonality (the area Jacobian of a pure shear is 1−∣g∣2=1−O(g2)1 - |g|^2 = 1 - O(g^2), so even the magnification enters only at second order). Hence

∂x0∂ga∣g=0≈0⟹Qsel=∇gPsel∣g=0≈0.\left.\frac{\partial x_0}{\partial g_a}\right|_{g=0} \approx 0 \quad\Longrightarrow\quad Q^{\mathrm{sel}} = \nabla_g P_{\mathrm{sel}}\big|_{g=0} \approx 0.

The first-order selection term is spin-forbidden. This is not a numerical accident; it is why the correction cannot be a first-order additive shift and must appear in RR (the calibration / multiplicative channel).

4.4 Second derivative RselR^{\mathrm{sel}}

Differentiate (4.5) again. Using φ′(u)=−uφ(u)\varphi'(u)=-u\varphi(u) and defining the "edge-curvature" E≡umax⁡φ(umax⁡)−umin⁡φ(umin⁡)E \equiv u_{\max}\varphi(u_{\max}) - u_{\min}\varphi(u_{\min}):

∂2s∂ga∂gb=−Eσf2 ∂Mf∂ga∂Mf∂gb⏟(i) box curvature    − Dσf ∂2Mf∂ga∂gb⏟(ii) 2nd-order flux response.(4.6)\frac{\partial^2 s}{\partial g_a\partial g_b} = \underbrace{-\frac{E}{\sigma_f^2}\,\frac{\partial M_f}{\partial g_a}\frac{\partial M_f}{\partial g_b}}_{\text{(i) box curvature}} \;\;\underbrace{-\,\frac{D}{\sigma_f}\,\frac{\partial^2 M_f}{\partial g_a\partial g_b}}_{\text{(ii) 2nd-order flux response}}. \tag{4.6}

Term (i) is ∝(∂Mf/∂g)2∝(∂x0/∂g)2\propto (\partial M_f/\partial g)^2 \propto (\partial x_0/\partial g)^2, which is negligible for the same spin-0 reason that killed QQ. The surviving signal is term (ii), and within (4.4) its leading part is the flow Hessian ∂2x0/∂g2\partial^2 x_0/\partial g^2 — the genuine second-order (spin-2 ×\times spin-2 →\to spin-0) response of the flux moment:

Rabsel  ≈  −λ std0σf 1N∑iMf,i Di ∂2x0,i∂ga∂gb.(4.7)R^{\mathrm{sel}}_{ab} \;\approx\; -\frac{\lambda\,\mathrm{std}_0}{\sigma_f}\,\frac1N\sum_i M_{f,i}\, D_i\, \frac{\partial^2 x_{0,i}}{\partial g_a \partial g_b}. \tag{4.7}

This is the nonzero content of the selection correction, and it is exactly what jax.hessian extracts at inference.py:183. Summary of §4: QselQ^{\mathrm{sel}} is spin-forbidden and ≈0\approx 0; RselR^{\mathrm{sel}} is allowed and carries the whole effect — consistent with the empirical finding that the correction lives in RR, not in the first-order multiplicative bias.

5. From one Psel(g)P_{\mathrm{sel}}(g) to a per-object catalogue correction

5.1 Binning over σf\sigma_f (selection_pqr_binned, inference.py:187)

Psel,iP_{\mathrm{sel},i} depends on object ii through a single scalar, its noise σf,i\sigma_{f,i}, which enters only the CDF weight (2.1) and not the flow pushforward TT. Recomputing a full flow pushforward per object would be wasteful, so we bin: histogram the catalogue's σf,i\sigma_{f,i} into a handful of bins, take one representative σf\sigma_f per bin, and evaluate selection_pqr once per bin (inference.py:221-227). Two design points:

  • Common random numbers across bins. Every bin reuses the same base draws ziz_i (same key), so the PQR varies smoothly across the σf\sigma_f sweep — differences between bins reflect the CDF weight, not MC jitter.
  • Each bin's PQR is converted to log-totals by qr_log_totals, giving q_tot_b (n_bins, 2) and r_tot_b (n_bins, 2, 2) — the per-bin Qtotsel,RtotselQ^{\mathrm{sel}}_{\mathrm{tot}}, R^{\mathrm{sel}}_{\mathrm{tot}}.

5.2 Attaching a selection term to each object (_selection_terms, apply_selection_correction.py:62)

_bins_from_sigma_f (:46) histograms σf,i=Σi[0,0]\sigma_{f,i}=\sqrt{\Sigma_i[0,0]} and returns, row-aligned to the catalogue, each object's bin index bin_idx. Each object then gathers its selection log-totals from its own bin:

sel_qtot = q_tot_b[bin_idx]   # (N, 2)
sel_rtot = r_tot_b[bin_idx]   # (N, 2, 2)

This realizes the per-object Qtot,isel,Rtot,iselQ^{\mathrm{sel}}_{\mathrm{tot},i}, R^{\mathrm{sel}}_{\mathrm{tot},i} of (1.2), with object ii carrying the selection response evaluated at its noise level (approximated by its bin's representative σf\sigma_f).

5.3 The subtraction, and why it is per object (net_qr_totals / bootstrap)

net_qr_totals (statistics.py:107) subtracts the gathered selection log-totals row-by-row before the sum-and-solve of (1.2). Attaching the term per object rather than as a single precomputed grand sum is what makes the uncertainty correct: bootstrap_independent_mult_bias (statistics.py:233, the _sub_sel closure at :319) resamples objects, and because each resampled object drags its own selection term along, the measured sum ∑Qtot,i\sum Q_{\mathrm{tot},i} and the selection sum ∑Qtot,isel\sum Q^{\mathrm{sel}}_{\mathrm{tot},i} co-vary correctly under the resample. A fixed global selection sum would sever that correlation and misstate the error bar.

5.4 The multiplicative bias

Apply (1.2) per shear arm (the ±\pm ring-test arms), then

m=g^+[0]−g^−[0]Δg−1,m = \frac{\hat g_{+}[0] - \hat g_{-}[0]}{\Delta g} - 1,

with and without the selection subtraction to isolate its impact; the driver prints exactly this Δ\Delta (apply_selection_correction.py:238-240).

6. Numerical choices and their justification

  • Plain MC, no importance sampling / no Pareto-k^\hat k. The measurement integral P(g)=∫pθ(x∣g) N(x;M,Σ) dxP(g)=\int p_\theta(x\mid g)\,\mathcal N(x;M,\Sigma)\,dx needs importance sampling and PSIS diagnostics because its integrand (a narrow Gaussian kernel) is peaked and heavy-tailed in weight. The selection integrand s∈[0,1]s\in[0,1] is bounded and smooth (2.1), so the estimator variance is a benign O(1/N)O(1/N) with no tail — a raw mean over N=217N=2^{17} prior draws suffices (inference.py:147, :165).
  • Evaluate at g0=0g_0=0 (inference.py:180). The BFD estimator is a linearization about the unsheared fiducial; Psel,Qsel,RselP_{\mathrm{sel}}, Q^{\mathrm{sel}}, R^{\mathrm{sel}} are the Taylor coefficients there.
  • sxs_x held fixed at [ prior_sigmax_log_scale_mean,0,0 ]≈[11.98,0,0][\,\texttt{prior\_sigmax\_log\_scale\_mean},0,0\,] \approx [11.98, 0, 0] (inference.py:168, config.py:48): the non-shear conditioning (galaxy size scale and the two centroid-covariance ellipticity components) is pinned to one representative value rather than marginalized over its full distribution. An approximation, and a natural place to check sensitivity if the correction ever matters at the 10−310^{-3} level.
  • One representative σf\sigma_f per bin. With enough bins this is accurate because PselP_{\mathrm{sel}} is smooth in σf\sigma_f; the ponytail: note at inference.py:212 records the obvious speedup (hoist the gg-Jacobian/Hessian of Mf(z,g)M_f(z,g) out of the loop, since σf\sigma_f only enters the CDF weight) if the bin count ever grows.

7. Sanity checks worth running

  1. Qsel→0Q^{\mathrm{sel}}\to 0. Print QselQ^{\mathrm{sel}} from selection_pqr; both components should be statistically consistent with zero at reasonable NN. A nonzero, NN-stable QselQ^{\mathrm{sel}} would signal either a spin leak in the flow or a bug in the destandardization (4.1).
  2. Band limits. As [fmin⁡,fmax⁡][f_{\min}, f_{\max}] widens to cover the whole flux support, s→1s\to 1, so Psel→1P_{\mathrm{sel}}\to 1 and Qsel,Rsel→0Q^{\mathrm{sel}}, R^{\mathrm{sel}}\to 0 — the correction must vanish when nothing is cut.
  3. Common-random-number smoothness. Sweep σf\sigma_f and confirm the per-bin PQR is smooth (no MC hash); if it is jagged, the shared key was lost.
  4. Reduction to pqr2g. apply_selection(pqr, None, None) must equal pqr2g(pqr) bit-for-bit (statistics.py:136).
  5. Finite-difference the flow response. Cross-check jax.hessian's ∂2x0/∂g2\partial^2 x_0/\partial g^2 against a central difference of the flow output — the RselR^{\mathrm{sel}} signal (4.7) rides entirely on this term.

Automated coverage lives in tests/test_selection_pqr.py and tests/test_pqr_bfd.py.

8. One-paragraph summary

Selection by a measured-flux band divides each object's likelihood by a gg-dependent survival probability Psel,i(g)P_{\mathrm{sel},i}(g) (1.1); differentiating turns that division into a per-object subtraction of the selection's own log-space PQR from the measurement's (1.2). Psel(g)P_{\mathrm{sel}}(g) is the prior-averaged difference-of-Gaussian-CDFs (2.1)–(2.2), estimated by reparameterized MC with frozen base draws so that gg-derivatives are exact pathwise gradients (§3). The chain rule (§4) shows the first derivative is spin-forbidden (Qsel≈0Q^{\mathrm{sel}}\approx 0, flux is spin-0) and the whole effect rides on the flow's second-order flux response ∂2x0/∂g2\partial^2 x_0/\partial g^2 inside RselR^{\mathrm{sel}}. The correction is binned over σf\sigma_f, gathered onto each object by its noise bin, and subtracted per object so the bootstrap stays correct (§5).
